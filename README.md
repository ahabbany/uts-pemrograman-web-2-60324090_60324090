# Aplikasi Perpustakaan (CRUD PHP & MySQL)

## Deskripsi
Aplikasi Perpustakaan ini merupakan sistem sederhana berbasis web yang dibangun menggunakan PHP dan MySQL. Aplikasi ini digunakan untuk mengelola data perpustakaan seperti kategori dan anggota.

Fitur utama:
- Create (menambah data)
- Read (menampilkan data)
- Update (mengubah data)
- Delete (menghapus data)

---

## Teknologi yang Digunakan
- PHP Native
- MySQL
- HTML, CSS
- XAMPP (Apache & MySQL)

---

## Cara Instalasi

### 1. Clone / Download Project

git clone https://github.com/username/perpustakaan.git

atau download manual lalu ekstrak ke: C:\xampp\htdocs\perpustakaan

---

### 2. Jalankan XAMPP
- Start **Apache**
- Start **MySQL**

---

### 3. Import Database
- Buka: `http://localhost/phpmyadmin`
- Buat database:

uts_perpustakaan_[NIM]

- Klik **Import**
- Masukkan file `.sql`
- Klik **Go**

---

### 4. Jalankan Aplikasi
Buka browser:

http://localhost/perpustakaan
